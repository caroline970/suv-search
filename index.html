Full-Size SUV Search — Captain's Chairs + Real 3rd Row

Prepared July 22, 2026 · Asking prices before tax/fees · Every listing is delivery-eligible nationwide

Criteria (locked)

  • Full-size body / real usable 3rd row — non-negotiable
  • 2nd-row captain's chairs — non-negotiable (must photo-confirm each; every model also offers a bench)
  • Black or navy exterior
  • ≤ 30,000 miles (ideal)
  • Budget: ideally $40–50k, up to $60–65k all-in
  • Better gas mileage preferred · delivery anywhere fine

Recommendation (short version)

Full-size + captain's + better MPG is a genuinely tight box. Two clean paths:

  • Path A — prioritize MPG: a diesel GMC Yukon / Chevy Suburban (~24/28 mpg). Catch: diesel + captain's + black/navy is rare, and the captain's-equipped ones run ~$60k+.
  • Path B — prioritize cool + value: the Jeep Wagoneer (~$45–60k) or Cadillac Escalade (~$59–63k) at ~16–18 mpg. Fuel costs ~$1,000–1,400/yr more than diesel.

Bottom line: unless saving ~$1,200/yr in gas is a priority, Path B gets a cooler truck with more choices and better pricing. If MPG truly matters, hunt a GMC Yukon Denali Diesel / Suburban Diesel. The Sequoia hybrid only nets ~21 mpg (barely better than the Wagoneer) at top-of-budget money — skip it. The Grand Highlander Hybrid is the MPG champ but is one size down from full-size.
